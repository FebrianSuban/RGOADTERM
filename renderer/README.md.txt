# RGOADTERM

Hyprland-inspired terminal emulator for Windows.

## Features

- PowerShell
- Dark glass UI
- Neon green theme
- Transparent window
- Blur effect
- Startup animation
- Custom title bar
- Terminal tabs UI
- Status bar
- Clock
- xterm.js terminal
- Portable EXE

## Requirements

Windows 10/11

Node.js 20 or newer.
