Panduan Penggunaan
Workspace, pane, shell, dan shortcut

Workspace dan Pane

  • + membuat workspace baru yang memiliki layout dan sesi terminal sendiri.
  • Pilih tab di bar atas untuk berpindah workspace; tombol × pada tab menutup workspace tersebut.
  • Pilih 1–4 Pane di Settings untuk menentukan jumlah terminal pada workspace aktif.
  • Tombol × di dalam pane menutup pane itu dan menata ulang pane yang tersisa.
  • Klik atau arahkan kursor ke pane untuk menjadikannya aktif.

Shell dan Scroll

  • Pilih PowerShell atau CMD dari menu SHELL untuk mengganti shell pada pane aktif saja.
  • Scroll output dengan roda mouse atau touchpad. Scrollbar disembunyikan, tetapi scroll tetap aktif.
  • Ctrl + C mengirim interrupt ke proses yang sedang berjalan di shell aktif.

Shortcut Keyboard

Ctrl + Shift + T
Membuat workspace baru.
Ctrl + Tab
Beralih ke workspace berikutnya.
Ctrl + Shift + →
Menambah satu pane, maksimal empat.
Ctrl + Shift + ←
Mengurangi satu pane dan mempertahankan pane aktif.
Ctrl + +
Memperbesar font pane aktif sebesar 2 px. Pada sebagian keyboard, gunakan Ctrl + Shift + =.
Ctrl + -
Memperkecil font pane aktif sebesar 2 px.
Ctrl + 0
Mengembalikan font pane aktif ke 14 px.
Ctrl + W
Menutup pane aktif jika ada beberapa pane; pada layout satu pane, menutup workspace aktif jika masih ada workspace lain.
Esc
Menutup popup Panduan atau Settings yang terbuka.

Tampilan dan Jendela

  • Pilih Dark atau Light di Settings untuk mengganti tampilan.
  • Tombol di kanan atas digunakan untuk minimize, maximize/restore, dan menutup aplikasi.
